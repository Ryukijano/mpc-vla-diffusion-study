## 1. Claims supported by this bundle

This bundle reproduces the core Horizon 1 experiments on the NVIDIA DGX Spark (GB10, Grace Blackwell):

| Experiment | Script / runner | What it shows |
|------------|-----------------|---------------|
| **EXP-001** | `run_ablation.py` | GCP component ablation — distribution fitting vs iterative compute + noise (DDPM, MIP, Regression, variants). |
| **EXP-002** | `run_experiments.py` | Three-family head-to-head comparison — MPC vs VLA vs Diffusion/Flow/MIP on Reaching, Reaching Cluttered, PushT. |
| **EXP-004** | `scripts/run_pareto_sweep.py` | Latency-performance Pareto frontier with step sweeps for DDPM, Flow Matching, MIP, MPC, VLA, Regression. |

The smoke test in `run_quick_test.sh` validates that all baseline families import and run before the full experiments.

> **Note:** EXP-003 (OOD robustness & manifold adherence) is not included in the one-command runner because it reuses trained checkpoints from EXP-001/002 and is run as a downstream analysis step. Artifacts produced by EXP-001/002 can be fed into EXP-003 if desired.

## 2. One-command reproduction

From the repository root:

```bash
bash repro/scripts/02_run_experiments.sh
```

This will:

1. Run a quick smoke test (`scripts/run_quick_test.sh`).
2. Generate demonstration data (`repro/scripts/01_download_data.sh` is also available as a standalone step).
3. Run EXP-001, EXP-002, and EXP-004 in sequence.
4. Save all results under `results/`.

To prepare the environment first, run:

```bash
bash repro/scripts/00_setup.sh
```

## 3. Hardware and runtime

| Item | Specification |
|------|---------------|
| Target hardware | NVIDIA DGX Spark (GB10 Grace Blackwell) |
| GPU | Blackwell GPU, sm_121, CUDA 12.8 |
| Memory | 128 GB unified (CPU + GPU) |
| Conda environment | `mpc_vla` (Python 3.11, PyTorch 2.12.0.dev+cu128) |

| Phase | Approx. wall-clock on GB10 |
|-------|---------------------------|
| Smoke test (`run_quick_test.sh`) | < 2 minutes |
| EXP-001 GCP ablation (`run_ablation.py`) | ~3 hours |
| EXP-002 three-family comparison (`run_experiments.py`) | ~6 hours |
| EXP-004 Pareto sweep (`scripts/run_pareto_sweep.py`) | ~5 hours |
| Report generation (`generate_report.py`) | ~30 minutes |
| **Total** | **~15-17 GPU-hours** |

The headline budget used in the study is **~16 GPU-hours** on DGX Spark.
